Teacher tips (read once)
  • Before the lesson: test this laptop + 2–3 phones on the school Wi-Fi for 5 minutes. Some networks block phones from reaching the laptop.
  • Length: 5 minutes for the first game, then 6–8 minutes once students know the rules. Two short games + the question review beats one long game.
  • Pairs work well: one phone per pair halves Wi-Fi load; one student steers, the other reads and answers. Use a pair nickname like "Mochi & Boba".
  • Avatars: allow ~2 minutes. Pressing Start pulls everyone into the game, even if they're still designing.
  • Who isn't answering? Press 📋 during the game and scan the code with your phone for a private list.
  • Rules in one breath: answer locker questions → loot → carry fuses to the generator. Tagged? Tag someone from another crew.
