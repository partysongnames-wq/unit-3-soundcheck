- Browser: headless Chromium (Playwright 1.63.0 build `chromium-1243`, preinstalled at `/opt/pw-browsers`), Node 22.22.0, Linux.

## Limitations

- Only Chromium was tested. Firefox, Safari and a real projector or classroom display were not.
- Fullscreen in a real browser needs a user gesture. Pressing F is one, but some locked-down school setups may block it; then the page shows the F11 message.
- The print check uses Chromium's print engine. Other browsers' print dialogs may scale slightly differently; print at 100% / "Default" margins.
- Text contrast was chosen by design (dark ink on cream, cream on navy). No automated WCAG contrast audit was run.
- Shuffle uses `Math.random` (only when the teacher presses Shuffle). The rest of the game is deterministic.
- Classroom suitability (timing, difficulty for 39–40 students) has not been tried with a real class.
