Welcome to Story Lantern

Ten words about stories and storytellers. Work in pairs or teams. Say your answers out loud — no phones needed.

Teacher setup (30 seconds)

  1. Press F for fullscreen (or F11 if blocked).
  2. Tick the words for today. Press Shuffle if you like.
  3. Set the timer minutes. Start it with T (optional).
  4. Put students in pairs. Turn on Scores for team points (optional).
  5. Press Start Discover. Use Space to reveal and → for the next word.

      Story frame (pairs)

      1. Once upon a time, there was ...
      2. One day, ...
      3. Although ..., ...
      4. In the end, ...

      Simple help: Write only 3 sentences. Use 3 words. Make the ending silly!

      Challenge

      Use all four words. Add one line of speech ("...") and a surprise ending. Tell it to another pair in 30 seconds.
